# DEAD OR ALIVE ｜ よいちゃんのチキチキたらいおとし

Phaser 3 製の落ちものキャッチゲームです。内部解像度は 540 × 960（9:16）。

## ▶ 遊ぶ

**https://nyanyamagari.github.io/yoithangame_1/**

PC・スマホのブラウザでそのまま遊べます（インストール不要）。

## 遊び方

- 制限時間 **60秒**。
- 上から降ってくる **ジュース（プラスアイテム）** を拾うと **+20pt**、**たらい（ミスアイテム）** に当たると **-50pt**。
- タイトル画面でプレイヤーキャラクターを選べます。横スクロール式で、**スワイプ / 左右の矢印 / ← → キー / 横に見えているキャラのタップ** で切り替え、中央の枠に止まったキャラが選択になります。選択は次回起動時も保持されます。
- 操作は **← → キー（A / D も可）** または **画面の左右をタップ（押しっぱなしで移動）**。
- **20秒ごと**にアイテムのスポーン数と落下速度が上がります（3段階）。
- リザルトでスコア・ジュース獲得数・たらい被弾数を表示。
- ハイスコアはブラウザの localStorage に保存され、タイトル画面に表示されます。

## 起動方法

### 公開版（GitHub Pages）

`main` ブランチに push すると、1〜2分で https://nyanyamagari.github.io/yoithangame_1/ に反映されます。

### ローカル（XAMPP）

Apache を起動して次の URL を開きます。

```bash
start http://localhost/game1/
```

ビルドは不要で、HTML/CSS/JS をそのまま配信するだけで動きます。
`index.html` をダブルクリックで直接開く（`file://`）と画像の読み込みが制限されるため、必ず Web サーバー経由で開いてください。

※ Phaser 3 は CDN（jsdelivr）から読み込むため、ネット接続が必要です。
※ ファイルを書き換えても反映されないときは、ブラウザのキャッシュが原因のことが多いので **Ctrl+F5** で再読み込みしてください。

## フォルダ構成

```
game1/
├── index.html              エントリ（読み込み順もここ）
├── css/
│   └── style.css           画面中央への配置と拡大縮小（配置はCSSのみで完結）
├── js/
│   ├── config.js           解像度・得点・難易度・アイテム表示サイズなど全設定
│   ├── storage.js          localStorage 読み書き（ハイスコア・選択キャラ）
│   ├── sfx.js              効果音（WebAudioで合成・音声ファイル不要）
│   ├── ui.js               背景/パネル/ボタンなど共通パーツ
│   ├── main.js             Phaser の起動設定
│   └── scenes/
│       ├── BootScene.js    画像読み込み＋雲/粒子テクスチャ生成
│       ├── TitleScene.js   タイトル・キャラ選択・遊び方・ハイスコア
│       ├── GameScene.js    本編（60秒）
│       └── ResultScene.js  リザルト・記録保存
└── assets/
    └── img/
        ├── chara_1.png     プレイヤー1（600 x 600）
        ├── chara_2.png     プレイヤー2（600 x 479）
        ├── logo.png        タイトルロゴ（910 x 273）
        ├── item_1.png      ジュース＝プラスアイテム（101 x 250）
        └── item_2.png      たらい　＝ミスアイテム　（400 x 340）
```

画像のキーは `BootScene.preload()` で割り当てています（キャラ画像は `GAME.CHARAS` の `id` をキーにして読み込みます）。

| ファイル | Phaser のキー | 用途 |
| --- | --- | --- |
| `chara_1.png` | `chara_1` | プレイヤー1 |
| `chara_2.png` | `chara_2` | プレイヤー2 |
| `logo.png` | `logo` | タイトルロゴ |
| `item_1.png` | `item_plus` | プラスアイテム（+20pt） |
| `item_2.png` | `item_miss` | ミスアイテム（-50pt） |

雲（`cloud`）と粒子（`spark`）だけはコードで生成しています。

## 画面の配置について

- Phaser 側は `Scale.NONE`（540 × 960 固定）で、`autoCenter` も使っていません。
- 中央寄せと拡大縮小は `css/style.css` だけで行っています。
  - `#game-wrapper` を flex で中央寄せ
  - `#game` は `aspect-ratio: 540 / 960` と `width: min(100%, (画面高 - 余白) * 540 / 960)`
  - `#game canvas` を `width/height: 100% !important` で枠いっぱいに拡大
- タップ座標は Phaser が canvas の実表示サイズから換算するため、拡大縮小しても正しく判定されます（リサイズ時に `game.scale.refresh()` を呼んでいます）。

## 調整したいとき

数値はすべて `js/config.js` にまとまっています。

| 項目 | 設定 |
| --- | --- |
| ロゴの表示幅 | `GAME.LOGO_WIDTH` |
| 制限時間 | `GAME.DURATION` |
| 難易度が上がる間隔 | `GAME.PHASE_SECONDS`（既定 20秒） |
| 得点 | `GAME.SCORE_PLUS` / `GAME.SCORE_MISS` |
| 移動速度 | `GAME.PLAYER_SPEED` |
| プレイヤーの画像・表示幅・立ち位置・当たり判定 | `GAME.CHARAS`（キャラごと） |
| アイテムの表示サイズ | `GAME.ITEM_HEIGHT`（高さ基準・幅は元画像の比率で自動計算） |
| アイテムの当たり判定 | `GAME.ITEM_BODY`（元画像のピクセル基準。`x` / `y` は左上からのオフセット） |
| 各段階のスポーン間隔・同時数・落下速度・たらい率 | `GAME.PHASES` |

`GAME.PHASES` は経過時間 0–20秒 / 20–40秒 / 40–60秒 に対応します。

| 段階 | スポーン間隔 | 同時数 | 落下速度 | たらい率 |
| --- | --- | --- | --- | --- |
| 0–20秒 | 780ms | 1 | 190–250 | 30% |
| 20–40秒 | 620ms | 1–2 | 250–340 | 36% |
| 40–60秒 | 500ms | 2–3 | 320–440 | 42% |

**難しすぎる / 簡単すぎるとき**は、`missRate`（たらいの割合）、`GAME.ITEM_BODY.miss` の `w`（たらいの当たり判定幅）、`GAME.CHARAS` の `body.w`（プレイヤーの当たり判定幅）あたりで調整できます。

## プレイヤーキャラクター

`js/config.js` の `GAME.CHARAS` にキャラごとの設定があります。先頭のキャラが初期選択です。

| 項目 | 内容 |
| --- | --- |
| `id` | 画像を読み込むときのキー（選択の保存にも使う） |
| `file` | `assets/img/` 以下の画像ファイル名 |
| `width` | ゲーム中の表示幅（高さは元画像の比率で自動計算） |
| `bottom` | ゲーム中の画像下端のY座標（草地の上端は 876） |
| `body` | 当たり判定。**元画像のピクセル基準**で `w` / `h`、画像左上からのオフセット `x` / `y` |

現在の設定では、どちらのキャラも当たり判定がほぼ同じ大きさ（表示上 約123×83px）になるようにしてあり、選ぶキャラで有利不利が出ません。
画像を差し替えてサイズが変わった場合は、`body` の値を新しい画像のピクセル数に合わせて直してください（画面端で見切れない移動範囲は `body` から自動計算されます）。

キャラを増やすときは `GAME.CHARAS` に追加し、画像を `assets/img/` に置くだけで横スクロールの並びに加わります（数の上限はありません。並び順は `GAME.CHARAS` の順）。

横スクロールの間隔や吸着の速さは `TitleScene.buildCharaSelect()` の `SPACING`、`snapTo()` の `duration` で調整できます。

## 称号

リザルトのスコアに応じて称号が表示されます（定義は `js/config.js` の `GAME.RANKS`）。

| スコア | 称号 | | スコア | 称号 |
| --- | --- | --- | --- | --- |
| 1001 〜 | 親衛隊の王 | | -2001 〜 | 愉悦王 |
| 601 〜 1000 | 親衛隊隊長 | | -1001 〜 -2000 | 愉悦部部長 |
| 301 〜 600 | 親衛隊の先輩 | | -501 〜 -1000 | 愉悦部先輩 |
| 0 〜 300 | 親衛隊 | | -1 〜 -500 | 愉悦部員 |

称号を増やす・変えるときは `GAME.RANKS` に `{ min, label, color, shade }` を追加してください（`min` の降順に並べる。判定は `GAME.rankOf(score)`）。

## 補足

- スコアはマイナスにもなります（たらいに当たりすぎた場合）。0止まりにしたい場合は `GameScene.onCatch()` の `this.score += gain;` の後にクランプを追加してください。
- 画像を差し替えるときは、同じキーで読み込めばサイズは `GAME.ITEM_HEIGHT` を基準に自動調整されます（当たり判定だけ `GAME.ITEM_BODY` の見直しが必要です）。
- localStorage のキーは `taraiotoshi.best`（ハイスコア）と `taraiotoshi.chara`（選択キャラ）です。
